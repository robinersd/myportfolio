# AI tool previews and logo sources

The Codex, Antigravity and Claude AI illustrations were generated with the built-in image_gen tool via the imagegen skill, using the existing TypeScript illustration as an edit reference. They show representative workflows rather than literal product screenshots.

Saved assets in this folder: `codex.png`, `antigravity.png`, `claude.png`.

## Shared edit constraints

Replace only the monitor content; preserve the person, pose, keyboard, chair, blue glow, backdrop, composition and landscape framing. Render legible text in perspective. One image, no collage or watermark.

## Codex

A dark AI coding assistant workspace, header clearly 'Codex'. Show a small task panel titled 'Refactor ProjectCard' and a code editor with file tab 'ProjectCard.tsx'. Short legible TypeScript sample: interface Project { name: string; year: number; } . Beside it, a brief assistant plan: 'Review component', 'Apply changes', 'Check results'. Neutral charcoal interface, white text, restrained light blue syntax colors.

On the right show an agent panel with a simple checklist: 'Plan', 'Edit', 'Verify'. Code editor on the left, agent panel on the right. Restrained blue accents and realistic UI spacing.
